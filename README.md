# ABW.by Валюты

Браузерное расширение (Manifest V3) для Firefox и Chromium-браузеров, которое
показывает цены на [abw.by](https://abw.by) в выбранной валюте — USD, EUR или
RUB — и возвращает исходные значения в BYN при переключении обратно. Курсы
берутся из открытого API Национального банка Республики Беларусь (НБРБ).

## Возможности

- Замена цен в BYN на USD / EUR / RUB на страницах abw.by.
- Точное восстановление исходного текста цен при возврате к BYN.
- Конвертер во всплывающем окне (USD / EUR / RUB → BYN).
- Собственные курсы для каждой валюты (переопределение курса НБРБ).
- Автообновление курсов каждые 4 часа; при ошибке используются сохранённые
  курсы.
- Никакой телеметрии и внешних запросов, кроме `https://api.nbrb.by`.

## Поддерживаемые страницы и селекторы

Расширение работает только с проверенными селекторами реальной разметки ABW.by
(снимки страниц хранятся в `examples/` и используются в тестах):

| Тип страницы                    | Элемент                | Селектор                              |
| ------------------------------- | ---------------------- | ------------------------------------- |
| Каталог (`car_catalog.html`)    | основная цена карточки | `.top__right > .price > .price-byn`   |
| Каталог (`car_catalog.html`)    | лизинговый платёж      | `.top__right > a.leasing-offer`       |
| Карточка авто (`car_page.html`) | основная цена          | `ul.price > li.byn`                   |
| Галерея (`car_page.html`)       | цена в полноэкранном окне | `.modal-info__price > .byn`        |
| Карточка авто (`car_page.html`) | лизинговый платёж      | `.detail-info > a.leasing__link`      |
| Карточка авто (`car_page.html`) | предложения лизинга    | `.detail-micro-list__item-action > span.text` |
| Главная (`index.html`)          | цена карточки          | `.card__price-block .card__price_byn` |
| Товар (`product_page.html`)     | основная цена          | `ul.price > li.byn`                   |

Правила безопасности разметки:

- Заменяется только число в текстовом узле; иконка НБРБ (`.nbrb-icon`)
  скрывается на время показа иностранной валюты и возвращается при BYN.
- Элементы управления сайтом (например, кнопка «Конвертер» на страницах
  объявления) сохраняются без изменений.
- Лизинговые подписи сохраняют формулировку (`Лизинг от …`, `В лизинг от …`,
  `от …`) и суффикс `/мес` или `/ месяц`.
- Уже существующие цены в USD/EUR/RUB, «Договорная», «Бесплатно», диапазоны
  `от … до …` и прочие неценовые числа не затрагиваются.
- Новая разметка ABW поддерживается только после сохранения реального снимка
  страницы в `examples/`, добавления узкого селектора и тестов.

## Модули

### `manifest.json`

Исходный манифест Firefox. Версия для Chromium генерируется скриптом сборки:
`background.scripts` заменяется на `background.service_worker`, блок
`browser_specific_settings` удаляется.

### `src/lib/rates.js`

Чистая логика валют: парсинг ответа НБРБ, конвертация BYN ⇄ USD/EUR/RUB,
учёт масштаба (у RUB `Cur_Scale = 100`), форматирование. Не обращается к
DOM, `browser`/`chrome` или сети.

### `src/background.js`

Единственный владелец сети: запрос курсов НБРБ с таймаутом 10 секунд,
кэширование, будильник обновления раз в 240 минут, обработка сообщений
всплывающего окна и content script, включая собственные курсы.

### `src/content/abw.js`

Самодостаточный IIFE для страниц ABW: реестр безопасных селекторов, замена
чисел, точное восстановление BYN, `MutationObserver` с объединением проходов
через `requestAnimationFrame`, реакция на изменение настроек через
`storage.onChanged`.

### `src/popup/`

Всплывающее окно: курсы НБРБ с флагами, редактирование собственных курсов,
конвертер, выбор валюты для цен на ABW, кнопка «Обновить» и время последнего
обновления.

### `tests/`

Vitest + JSDOM: 112 тестов на реальных HTML-снимках из `examples/`
(конвертация, восстановление, динамические узлы, иммунитет к неценовым
значениям), а также покрытие фоновой логики и popup.

## Приватность

- Единственный сетевой адресат — `https://api.nbrb.by/*` (только чтение
  курсов).
- Никакие данные пользователя не собираются и не отправляются.
- Локальное хранилище (`browser.storage.local`) содержит только:

| Ключ               | Назначение                                          |
| ------------------ | --------------------------------------------------- |
| `ratesData`        | кэш курсов НБРБ (`rates`, `ratesDate`, `fetchedAt`) |
| `lastError`        | текст последней ошибки обновления                   |
| `selectedCurrency` | выбранная валюта показа цен (BYN по умолчанию)      |
| `customRates`      | собственные курсы пользователя                      |

## Установка

### Firefox

1. Скачайте `abw-currencies-firefox.zip` со страницы релизов.
2. Откройте `about:config` и установите `xpinstall.signatures.required` в
   `false` (только для обычного Firefox; в Firefox Developer Edition/Nightly
   не требуется) — либо соберите и подпишите пакет через
   [addons.mozilla.org](https://addons.mozilla.org).
3. Откройте `about:addons` → «Установить дополнение из файла…» и выберите
   ZIP.

### Firefox (временная установка для разработки)

```sh
make run
```

### Firefox для Android

```sh
make run-android                 #stable-канал
make run-android-nightly         #ночной канал
```

### Chrome / Edge / Brave

1. Распакуйте `abw-currencies-chrome.zip` (или используйте каталог
   `build/chrome` после сборки).
2. Откройте `chrome://extensions`.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите каталог со
   сборкой.

## Разработка

### Требования

- Node.js 24+
- npm 11+
- `zip` (для сборки пакетов)

### Установка зависимостей

```sh
npm install
```

### Команды разработки

```sh
make test               # тесты с покрытием
make format             # форматирование Prettier
make lint               # проверка форматирования
make package-firefox    # сборка build/firefox + abw-currencies-firefox.zip
make package-chrome     # сборка build/chrome + abw-currencies-chrome.zip
make build              # format + lint + test + оба пакета
make clean              # удалить build/, coverage/ и ZIP-архивы
make run                # запустить во временном Firefox
make run-chrome         # запустить в изолированном Chromium
```

## Известные ограничения

- Если сайт ABW динамически заменяет цену уже отслеживаемого элемента на новое
  значение BYN, до следующей перезагрузки страницы конвертация продолжает
  считаться от сохранённого исходного числа.
- Лизинговые подписи конвертируются только в текстовых элементах без вложенных
  элементов (кнопки рядом с ценой не изменяются).
- Поддержка новых шаблонов страниц ABW требует свежего снимка `examples/` и
  нового узкого селектора с тестами — широкие запросы вида `.price`
  намеренно не используются.
