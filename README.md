# ABW.by Валюты

[![ABW.by Валюты — промо-изображение](icons/big_promo_raw.png)](icons/big_promo_raw.png)

Браузерное расширение (Manifest V3) для Firefox и Chrome-based браузеров, которое автоматически заменяет цены на ABW.by из белорусских рублей (BYN) в выбранную валюту: USD, EUR или RUB. Курсы берутся из публичного API Национального банка Республики Беларусь.

Основная функция расширения — менять отображаемые цены на страницах ABW.by, чтобы вы сразу видели стоимость в удобной валюте. При выборе `BYN` сайт возвращается к исходному виду.

## Возможности

- Замена цен на ABW.by из BYN в USD, EUR или RUB.
- Точный возврат к оригинальным ценам в BYN при выборе валюты `BYN`.
- Поддержка цен в каталоге объявлений, карточках автомобилей, галерее, главной странице и страницах товаров, а также лизинговых платежей.
- Popup с текущими курсами НБРБ и простым конвертером валют (USD / EUR / RUB → BYN).
- Пользовательские курсы валют — возможность задать свой курс для каждой валюты.
- Автоматическое обновление курсов каждые 4 часа.
- Работа с кэшированными курсами, если API временно недоступен.
- Никакой телеметрии: расширение обращается только к `https://api.nbrb.by`.

## Как пользоваться

1. Установите расширение в Firefox или Chrome-based браузер (см. «Установка»).
2. Откройте popup расширения (иконка на панели браузера).
3. В поле выбора валюты выберите `USD`, `EUR`, `RUB` или `BYN`.
4. Откройте или обновите страницу на `https://abw.by/`.
5. Цены на странице будут заменены на выбранную валюту.
6. В блоке конвертера можно перевести сумму из USD / EUR / RUB в BYN.
7. При желании задайте собственный курс — он будет использоваться для цен на ABW.by и в конвертере.

## Какие цены заменяются

Расширение работает на проверенных страницах ABW.by и заменяет только цены:

- Каталог объявлений — цена в карточке и лизинговый платёж.
- Карточка автомобиля — основная цена, цена в полноэкранной галерее, лизинговый платёж и предложения лизинга.
- Главная страница — цена в карточке.
- Страница товара — основная цена.

При этом расширение аккуратно обходит всё остальное:

- Уже существующие цены в USD/EUR/RUB, «Договорная», «Бесплатно» и диапазоны «от … до …» не затрагиваются.
- Иконка НБРБ рядом с ценой временно скрывается и возвращается при показе BYN.
- Кнопки и элементы управления сайта (например, «Конвертер») остаются без изменений.
- Подписи лизинга сохраняют исходную формулировку («Лизинг от …», «В лизинг от …», суффикс «/мес»).

## Модули

### `manifest.json`

Базовый манифест расширения: имя, версию, разрешения, popup, background script и content script для ABW.by.

Для Firefox используется исходный `manifest.json`, а для Chrome build-скрипт генерирует совместимый манифест (заменяет `background.scripts` на `background.service_worker`, удаляет `browser_specific_settings`).

Важные разрешения:

- `storage` — хранение курсов, ошибок обновления и выбранной валюты.
- `alarms` — периодическое обновление курсов.
- `https://api.nbrb.by/*` — загрузка курсов НБРБ.
- `https://abw.by/*` — запуск content script на ABW.by.

### `src/background.js`

Фоновый модуль расширения — единственное место, где расширение работает с сетью.

Функции:

- Загружает курсы НБРБ с таймаутом 10 секунд.
- Кэширует курсы и обновляет их по расписанию — раз в 240 минут.
- Не теряет последние валидные курсы при ошибке API.
- Отвечает на сообщения popup и content script, включая пользовательские курсы.

### `src/content/abw.js`

Content script, который работает на страницах ABW.by.

Функции:

- Читает выбранную валюту и сохраненные курсы из `browser.storage.local`.
- Находит элементы цен на странице через реестр проверенных селекторов.
- Сохраняет оригинальный BYN-текст, чтобы можно было точно вернуть исходное отображение.
- Конвертирует BYN в выбранную валюту и заменяет цену без добавления второго значения рядом.
- Обрабатывает динамически добавленные элементы через `MutationObserver`.
- Реагирует на изменение выбранной валюты без переустановки расширения или перезагрузки страницы.

### `src/lib/rates.js`

Чистый модуль бизнес-логики без зависимостей от браузерных API и DOM.

Функции:

- `parseRates` — извлекает USD, EUR и RUB из ответа API НБРБ (с учётом масштаба, например `Cur_Scale = 100` у RUB).
- `convert` — переводит сумму из выбранной валюты в BYN.
- `convertFromBYN` — переводит сумму из BYN в выбранную валюту.
- `parseBynPrice` — извлекает числовую цену из текста ABW.by.
- `formatDisplayPrice` — форматирует цену для отображения на странице.
- `formatRateLabel`, `formatRate`, `formatDate`, `formatTime` — форматирование курсов и дат для popup.

### `src/popup/`

Интерфейс расширения.

Функции:

- Показывает текущие курсы USD, EUR и RUB к BYN с флагами.
- Показывает время последнего обновления.
- Позволяет вручную обновить курсы.
- Содержит простой конвертер валют в BYN.
- Позволяет выбрать валюту, в которую будут заменяться цены на ABW.by.
- Позволяет задать собственные курсы валют.

### `tests/`

Тесты на Vitest + JSDOM — 112 тестов на реальных HTML-снимках страниц ABW.by из `examples/`.

Покрывают:

- Парсинг ответа НБРБ.
- Конвертацию валют.
- Форматирование цен.
- Поведение content script на сохраненных HTML-примерах ABW.by.
- Восстановление оригинальных BYN-цен.
- Иммунитет к неценовым значениям («Договорная», «Бесплатно», диапазоны).
- Фоновую логику и popup.

## Приватность

Единственный сетевой адресат расширения — `https://api.nbrb.by/*`, и только для чтения курсов валют. Никакие данные пользователя не собираются и не отправляются.

Выбранная валюта, последние курсы, пользовательские курсы и текст последней ошибки обновления хранятся локально в браузере через `browser.storage.local` (ключи `ratesData`, `lastError`, `selectedCurrency`, `customRates`).

## Установка

### Firefox

1. Скачайте `abw-currencies-firefox.zip` со страницы релизов.
2. Откройте `about:config` и установите `xpinstall.signatures.required` в `false` (только для обычного Firefox; в Firefox Developer Edition/Nightly не требуется) — либо соберите и подпишите пакет через [addons.mozilla.org](https://addons.mozilla.org).
3. Откройте `about:addons` → «Установить дополнение из файла…» и выберите ZIP.

### Firefox (временная установка для разработки)

```sh
make run
```

### Firefox для Android

```sh
make run-android                 #stable-канал
make run-android-nightly         #ночной канал
```

### Chrome / Edge / Brave

1. Распакуйте `abw-currencies-chrome.zip` (или используйте каталог `build/chrome` после сборки).
2. Откройте `chrome://extensions`.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите каталог со сборкой.

## Разработка

### Требования

- Node.js 24+
- npm 11+
- `zip` (для сборки пакетов)

### Установка зависимостей

```sh
npm install
```

### Команды разработки

```sh
make test               # тесты с покрытием
make format             # форматирование Prettier
make lint               # проверка форматирования
make package-firefox    # сборка build/firefox + abw-currencies-firefox.zip
make package-chrome     # сборка build/chrome + abw-currencies-chrome.zip
make build              # format + lint + test + оба пакета
make clean              # удалить build/, coverage/ и ZIP-архивы
make run                # запустить во временном Firefox
make run-chrome         # запустить в изолированном Chromium
```

## Известные ограничения

- Если сайт ABW динамически заменяет цену уже отслеживаемого элемента на новое значение BYN, до следующей перезагрузки страницы конвертация продолжает считаться от сохраненного исходного числа.
- Лизинговые подписи конвертируются только в простых текстовых элементах — кнопки рядом с ценой не изменяются.
- Поддержка новых шаблонов страниц ABW добавляется только после сохранения реального снимка страницы в `examples/` и написания тестов — «широкие» замены цен намеренно не используются.
